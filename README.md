

\# Proyecto Flask - Videojuegos



Aplicación web desarrollada con Flask y MySQL para gestionar videojuegos mediante operaciones CRUD.



\## Integración continua

\[!\[Codecov](https://codecov.io/gh/gapda1/videojuegos-login/graph/badge.svg)](https://codecov.io/gh/gapda1/videojuegos-login)



\## Pruebas automatizadas



El proyecto cuenta con 12 pruebas automatizadas utilizando pytest.



Las pruebas se ejecutan automáticamente mediante GitHub Actions.
